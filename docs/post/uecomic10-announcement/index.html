サークル「InTheDayDream」としてUEComic10に参加しています。私は初日行けないので、2日目と3日目（11月21日と11月22日）に頒布します。ただし3日目は少々呼び出しをくらっており、昼～は私が売り子ではないです。

内容

表紙と裏表紙は知り合いに完全にお任せして描いてもらいました。オタクの皆さんを騙してアルゴリズムとデータ構造を知ってもらおうかなという意気込みです。

目次を掲載しておきます。

  • まえがき
  • 第1章: エルゴノミクス・二分探索
  • 第2章: 競プロにおけるゼータ変換・メビウス変換と累積和
  • 第3章: Suffix Arrayの構築
  • 第4章: Heavy Light Decomposition
  • あとがき

本当はAVL木についてやCHTに関しても盛り込みたかったんですが、十分な時間が取れませんでした。 こういうのは時間で判断はできないものですが、執筆パートだけでも1章あたり5時間とかは余裕でかかっているので、最低限のクオリティは大丈夫だと思います。

後で本全体を公開する予定です。今の時点でもpdfではないですが公開しています。事前に内容を知りたい人は私のgithubを見に行ってください。すなわち、買ってくれる人は僕にお布施するつもりで買ってくれるといいかなと思います。
